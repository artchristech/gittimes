Eleven Claude Skills Clone Apps Without Touching Original Code 🔗

Free MIT-licensed toolkit reverse-engineers, rebuilds, and improves apps using only public data and user feedback

Jakeschincariol/replica-skill · Python · ▲ 155 in 1d 4d old

Jakeschincariol/replica-skill delivers eleven autonomous Claude skills that clone any application through clean-room reverse engineering. Rather than copying code, the system analyzes public interfaces—help centers, pricing pages, walkthroughs—and reconstructs features, flows, and data models from scratch.

Each skill handles a specific phase: /replica-recon maps screens and user journeys, /replica-architect selects the tech stack, /replica-build constructs the app, /replica-test hunts bugs, and /replica-entrepreneur scrapes user complaints to fix pain points in the clone. The process runs locally, requires only Python 3.8+, and needs no API keys or external services. Outputs accumulate in a replica/ folder, guiding developers from initial reconnaissance to a branded, deployable product with landing pages and store listings. By focusing on behavior and user experience—not proprietary assets—the toolkit enables indie hackers and builders to create competitive alternatives while sidestepping legal risks associated with direct code copying. The workflow enforces ethical boundaries: skills refuse to replicate logos, copy, or content, ensuring clones innovate on function rather than imitation.

The catch: The system relies entirely on Claude’s interpretive capabilities, meaning accuracy varies with app complexity and public documentation quality, and there’s no guarantee the cloned app will match the original’s performance or scalability without significant manual refinement.

Why this leads today It enables builders to reverse-engineer, rebuild, test, and fix any app using free, MIT-licensed Claude skills, automating app iteration and bug fixing at scale.

Use Cases
  • Indie hacker cloning a scheduling tool to improve booking flow
  • Startup reverse-engineering a SaaS dashboard to add requested features
  • Developer building a open-source alternative to a closed-source app

5 rolls up 460 merged PRs since v0.21.4 into a stable release, focusing on its core innovation: a closed learning loop where the agent autonomously creates skills from complex tasks and improves them during use.

ClaudeAnimationBase Turns AI Prompting Into Hand-Painted Cartoon Frames 🔗

Uses p5.js and p5.brush to generate frame-by-frame animations from Claude Opus 5.5 storyboards

JohnHeibel/ClaudeAnimationBase · JavaScript · ▲ 51 in 1d 5d old

JohnHeibel/ClaudeAnimationBase is a starter kit that lets developers animate hand-painted cartoons using AI-generated code. Built with p5.

js and p5.brush, it centers on Clawd, a character with 31 predefined emotions, and includes a guide for prompting Claude Opus 5.5 to produce storyboards, shot-by-shot animation logic, and contact sheets before rendering final video. The kit automates the animation pipeline: users ask the model to storyboard a scene, generate drawing code per frame, validate output via contact sheets, and compile to video.mp4 using ffmpeg. All animations follow strict principles — handmade aesthetics, continuous motion, brush-stroke medium, and narrative purpose in every scene — distilled from the creator’s music video experiments.
Developers interact with the project through Claude Code or any coding agent, first reading ANIMATION_GUIDE.md to understand prompting strategies, then iterating on broad or specific instructions to explore the model’s reasoning depth. The guide emphasizes swapping characters, creating new emotions, or injecting custom reference images to test adaptability. Rendering relies on Node.js, Google Chrome, and ffmpeg, with performance varying by GPU: watercolor fills in p5.brush slow integrated graphics significantly, prompting recommendations to substitute fills for faster iteration.
The project lowers the barrier to expressive, AI-assisted animation by coupling creative direction with technical execution, turning natural language prompts into timed, stylistically consistent 2D sequences. It demonstrates how structured prompting can align generative models with animation principles like timing, anticipation, and follow-through.
The catch: Without a dedicated GPU, watercolor-based rendering in p5.brush becomes prohibitively slow, limiting real-time iteration on integrated graphics.

Why this leads today It provides a practical, reusable toolkit that lowers barriers for artists and developers to create expressive hand-painted animations using AI, with ready-to-use assets and clear guidance.

Use Cases
  • Animators prototyping emotion-driven character sequences
  • Educators teaching animation principles via AI collaboration
  • Developers testing multimodal prompting in creative coding contexts

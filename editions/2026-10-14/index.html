NVIDIA's USD BRep Library Enables Precise NURBS Modeling in OpenUSD Pipelines 🔗

Standalone C++/Python toolkit bridges CAD solids with scene description for industrial digital twins

NVIDIA-Omniverse/usd-brep · C++ · ▲ 364 in 1d 5d old · Latest: v1.0.0

NVIDIA-Omniverse/usd-brep delivers a standalone library for NURBS-based boundary representation solid modeling, integrating directly with OpenUSD. It provides C++ and Python APIs to create, edit, and exchange BRep solids—enabling precise mechanical CAD geometry within USD-based workflows.

The library supports import and export of STEP, IGES, and JT formats, positioning it as a critical tool for manufacturers and simulation engineers building photorealistic digital twins. By embedding BRep capabilities into USD, it eliminates the need for tessellation approximations that lose precision in downstream physics or rendering stages.

Built on NVIDIA’s Omniverse stack, the project leverages Packman for dependency management and requires specific toolchains: Visual Studio 2019/2022 with MSVC v142 on Windows, or build-essential on Linux. macOS users must run prebuild steps to generate schema resources. The v1.0.0 release marks the first public availability of these core modeling primitives, previously confined to internal Omniverse modules.

The catch: Windows-only C++ support limits cross-platform accessibility, and the reliance on specific Visual Studio toolchain versions creates friction for teams using alternative build systems or newer compiler versions.

Use Cases
  • Mechanical engineers importing STEP assemblies into USD-based simulation
  • CAD vendors adding BRep-solid export to Omniverse-connected tools
  • Digital twin creators preserving NURBS precision in lighting and physics pipelines

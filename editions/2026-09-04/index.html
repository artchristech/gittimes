Ryze-AI-Adgent/open-seo-mcp-skills delivers SEO and generative engine optimization (GEO) capabilities directly inside Claude through the Model Context Protocol. Instead of relying on third-party dashboards or paying marked-up fees for DataForSEO calls, the project wires live data from a user’s own Google Search Console, GA4, and Google Ads accounts into Claude skills.

Users can run site audits, uncover keyword gaps, track rankings, and analyze backlinks using real click and impression data—not estimates. The skills also pull competitor insights and SERP data from DataForSEO, already integrated via the Ryze MCP connector, eliminating the need to manage API keys or absorb hidden costs. The MIT-licensed code invites customization, letting teams adapt workflows to internal tools or compliance needs.

The catch: The project assumes users already have access to Google Search Console, GA4, and Ads accounts; without these, core functionality falls back to limited DataForSEO-only modes, reducing its differentiator versus standard paid tools.

Nahrek's PolyLedger unifies Polymarket data in queryable DuckDB files 🔗

Resumable indexer streams on-chain trades and market metadata via HyperSync

nahrek/polyledger · Python · 301 stars 1d old

PolyLedger pulls every market from Polymarket's CLOB API and streams OrderFilled events from Polygon using Envio HyperSync, writing both into a single DuckDB file. The indexer is resumable by design, committing rows and block cursor in one transaction so interrupted runs pick up exactly where they left off.

It handles both V1 and V2 contract layouts with separate checkpoints, validates API responses via Pydantic, and uses exponential backoff with jitter for resilient networking. Gap recovery fills missing token IDs from the Gamma API, and one command exports all tables to Parquet for use with pandas, Polars, or Spark. Requires Python 3.11+ and a free HyperSync token from envio.dev.
The catch: The project assumes HyperSync availability and does not currently support alternative chains or layer-2s beyond Polygon.
